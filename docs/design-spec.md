# 设计规范 · macOS 菜单栏重设计

> 版本 2.0.0 · 2026-10-18 · 对应原型 `index.html` 与 `src/js/config.js`

## 1. 设计目标

1. **可扫视**：状态信息按功能聚类，扫视成本随分区数量下降，而非图标数量上升
2. **可生长**：应用持续增加时，视觉密度不增加（增长只发生在溢出芯片的数字上）
3. **同源一致**：任何屏幕、任何外观、任何密度下，状态语义保持一致
4. **零噪音**：运行中/未读等高频信息用最小视觉面积（圆点/徽标）表达

## 2. 五区结构

右侧从左至右分为五区，区间以 1pt 细线（不透明度 18%）+ 8pt 间距分隔：

| 分区 | 内容 | 规则 |
| --- | --- | --- |
| 系统区 | Wi-Fi、声音、电池 | P0 常驻，单色渲染；充电时电池转绿并叠加闪电；低电量转红并常显百分比 |
| 输入法区 | 当前输入法（如「拼」） | 中文输入时高亮（绿点），英文输入时弱化（50% 不透明度） |
| 通信区 | 有未读消息的应用 | 数字徽标（上限 99+）；无未读时**分区与分隔线整体隐藏** |
| 工具区 | AI / 开发工具 | 最多 3 个置顶；运行中任务（P1）优先于用户置顶占位 |
| 托盘区 | 聚焦搜索、控制中心、日期时间 | 始终可见；时钟默认中文紧凑格式「10月16日 周五 09:26」 |

## 3. 优先级模型

- **P0 常驻不可折叠**：系统区、托盘区、时钟。任何密度与屏幕配置下保持可见
- **P1 条件可见**：输入法（中文输入时）、有未读的通信应用、正在运行任务的工具——出现即占据工具区空位
- **P2 可折叠**：其余第三方工具默认收入溢出区，可手动置顶（≤3），上限满时给出明确提示

**抢占规则**：P1 运行中任务出现时，若工具区已满，将优先级最低的置顶项换入溢出区（见原型 04 节「任务突发」）。

## 4. 度量令牌

| 令牌 | 宽松（默认） | 紧凑 | 说明 |
| --- | --- | --- | --- |
| 栏高 | 28pt | 24pt | 原型 px 实现为 30px / 26px（演示可读性） |
| 图标 | 16pt | 16pt | 统一光学尺寸 |
| 命中区域 | 20×20pt | 18×18pt | 悬停高亮为 6pt 圆角 |
| 区间距 | 8pt | 8pt | 分区内部间距 |
| 分隔线 | 1pt @ 18% | 1pt @ 18% | 仅出现在有内容的区间之间 |
| 徽标 | 红 #FF3B30 | — | 数字 9.5pt 粗体 |
| 运行圆点 | 绿 #30D158 | — | 6pt，1.8s 呼吸周期 |

语义色对齐 macOS 系统色命名：`--sys-green / --sys-red / --sys-orange / --badge-bg`。

## 5. 状态语义

| 状态 | 视觉编码 | 冗余编码 |
| --- | --- | --- |
| 运行中 | 绿色呼吸圆点 | 悬停提示「· 运行中」 |
| 有未读 | 红色数字徽标 | 悬停提示「· N 条未读」 |
| 充电中 | 绿色电池 + 闪电 | 悬停提示「· 充电中」 |
| 电池供电 | 单色电池 | 悬停提示百分比 |
| 低电量 | 红色电池 + 百分比 | 悬停提示「电量低」 |
| 专注模式 | 托盘区月亮图标 | 悬停提示「专注模式已开启」 |
| 远程连接 | 连接徽标 + 圆点（绿/琥珀/红） | 悬停提示连接质量 |
| 已移除项 | 40% 不透明度 + 删除线 | 悬停提示「已移除：…」 |

原则：**色彩不是唯一传达手段**，每个色彩状态都附带文字冗余编码。

## 6. 全天候状态矩阵（原型 04 节）

| 组 | 状态 | 设计响应 |
| --- | --- | --- |
| 一天中的不同时候 | 早间 09:26 | 标准形态（与诊断截图同时刻） |
| | 午后 15:03 | 双任务并发，圆点并列 |
| | 晚间 21:47 | 专注模式月亮出现，布局不变 |
| | 深夜 02:15 | 日期翻转；通信区因无未读隐藏；过夜任务保留圆点 |
| 任务与通知 | 全部空闲 | 圆点与徽标全部消失 |
| | 多任务并发 | 密度不增加 |
| | 任务突发 | P1 自动占位，换出优先级最低置顶项 |
| 系统与容量 | 充电中 / 电池供电 / 低电量 | 电池三态语义 |
| | 应用增长 | 仅芯片数字增长（+7 → +12） |

## 7. 多屏幕规则（原型 05 节）

| 配置 | 行为 |
| --- | --- |
| 单屏 | 完整菜单栏（基准形态） |
| 双屏（默认） | 主屏：应用菜单 + 五区；副屏：纯状态条，五区同源、无应用菜单 |
| 三屏及以上 | 同双屏；Dock 跟随指针所在屏幕（系统默认，不干预） |
| 竖屏副屏 | 按「系统 → 时钟 → 通信 → 工具」顺序收缩 |
| 全屏应用 | 该屏菜单栏自动隐藏，指针移至顶部呼出；其他屏不受影响 |
| 远程会话 | 收敛为单一连接徽标（圆点 = 连接质量） |
| 不同分辨率/缩放 | 0.5×/1×/2× 缩放；栏高 24/28pt 两档 |
| 刘海屏 | 状态区避开刘海安全区；或采用 Thaw 式次级状态栏双行方案 |

核心不变式：**应用菜单只属于主屏；状态信息在所有屏幕同源可见；宽度不足时优先折叠，绝不挤压图标。**

## 8. 交互规格

| 交互 | 规格 |
| --- | --- |
| 悬停 | 120ms 圆角高亮 + 名称/状态提示（仅 hover 设备） |
| 点击「+N」 | 180ms 展开管理面板；右溢出时向左翻转 |
| 置顶 | 图标回到工具区；满 3 个时面板内提示 |
| 键盘 | Tab 全流程可达；Enter/Space 触发；Esc 关闭；焦点在面板内圈定 |
| 徽标更新 | 数字变化即时反映；运行圆点 1.8s 呼吸 |
| 动效降级 | `prefers-reduced-motion` 时停止呼吸与过渡 |

## 9. 已知边界与取舍

- 原型为**设计提案**，不操作真实 NSStatusItem；落地需处理 macOS 26/27 的 API 变更（见 docs/inspiration.md）
- 副屏默认不显示应用菜单是为降低噪音；需要时可在设置中开启（以牺牲简洁换取可达性）
- 中文紧凑时钟在窄屏副屏可退化为「周六 02:15」短格式（竖屏场景已演示）
